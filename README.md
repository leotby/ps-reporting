# Reporting Produits Structurés

Projet personnel, non affilié à Natixis.

Aucune donnée incluse : l'outil lit en mémoire les fichiers Excel que l'utilisateur dépose, sans aucun accès réseau.

Utilisation : télécharger `ps-reporting.html`, puis l’ouvrir par double-clic dans Edge ou Chrome.

Un seul fichier HTML, lisible, sans installation.

1. Textes du PDF (encadré « Suivi des risques » et mention générale) : ouvrir `ps-reporting.html` avec le Bloc-notes ; ils sont tout en haut, sous le commentaire « TEXTES DU PDF ».
2. Dans chacun des deux blocs, remplacer « [texte V1 à fournir] » par le texte voulu, entre les balises, sans toucher aux balises.
3. Enregistrer, puis recharger la page dans Edge ou Chrome.
