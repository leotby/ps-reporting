# Reporting Produits Structurés

Projet personnel, non affilié à Natixis.

Aucune donnée incluse : l'outil lit en mémoire les fichiers Excel que l'utilisateur dépose, sans aucun accès réseau.

Utilisation : télécharger `ps-reporting.html`, puis l’ouvrir par double-clic dans Edge ou Chrome.

Un seul fichier HTML, lisible, sans installation.
